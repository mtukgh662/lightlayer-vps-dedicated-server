## 带宽口径比 CPU 更能决定价格

先看 Lightlayer 自己表里一处反常的地方。双路 E5-2698V3 配 128G 内存那台 $372，单路 E5-2670V3 配 32G 那台 $415。CPU 和内存都翻了倍，价格反而低 43 美元，差别落在带宽上：128G 那台只给 1G 国际口径，32G 那台可以选 100M 优化。

同类价差在竞品身上更直白。RAKsmart 同一台 E3-1230 配 16G 内存和 1T HDD，BGP 1000M 是 $89/月，换成大陆优化 1000M 就是 $199/月，机器没变，端口都是 1000M，110 美元的差价全在“回国走哪条线”上。HostEase 那边，10G 端口的 E-2436 是 $239/月，端口提到 40G 后 2×Gold 4210 要 $389/月，再上到 100G 端口配 300T 流量，直接 $1,499/月。

所以看到“100M 优化 / 1G 普通 / 1G 国际”三选一，第一个要问清楚的是这三种口径是否同价。2024 年那份第三方记录把三种口径挤在同一格，没有分列价格，既可能是同价可选的配置项，也可能是记录者没拆开。在购物车里切换一下配置就能看出来。

“不限流量”四个字同样要拆开看。100Mbps 端口跑满一个月，理论流量上限约 32TB；1Gbps 跑满约 324TB。所谓不限，意思是不额外计费，实际能跑多少由端口决定。要不要为更大的端口多付钱，取决于你一个月能不能跑过 32TB。

## 常见问题

**不限流量是真的不限吗？**

端口决定天花板，100M 端口约 32TB/月，1G 端口约 324TB/月。至于有没有公平使用条款、超量之后是限速还是停机，公开页面没写清楚，下单前用工单确认一句最稳妥。这是我认为最该问、也最容易被跳过的一条。

**100M 优化口建站够不够？**

够。普通企业站和博客的峰值带宽通常只有几 Mbps，100M 端口留出的余量已经很大。页面打开速度取决于线路质量和机房到用户的路由，跟端口数字关系不大。真正吃端口的是下载、视频、镜像分发这类持续大流量场景。

**促销价买了以后续费会不会涨？**

双十一活动页写明“续费同价”，但促销机型限量、每人限购 2 台。续费周期的实际金额在购物车里会单独列出，结账前那一步看到多少就是多少，别只盯着首期价。

**支持什么付款方式，能不能退款？**

第三方活动页写明支持支付宝和 PayPal，付款页会列出全部可选项。退款条款我没有在公开页面找到明确说明，如果你对试用期有要求，下单前直接问客服，别默认有几天无理由退款。
